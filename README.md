# Mark's Barbershop Website

A multi-page website developed for a local barbershop using **HTML, CSS, and JavaScript**.

The project focuses on creating a clean, organized online presence where visitors can learn about the business, explore its work, meet the barbers, and find contact information.

## Features

- **Home Page:** Introduces the barbershop and its branding.
- **About Page:** Provides information about the business.
- **Gallery Page:** Showcases images of haircuts and barbering work.
- **Team Page:** Introduces the barbershop's team.
- **Contact Page:** Provides a way for visitors to contact the business.
- **Consistent Navigation:** Allows visitors to move between the website's pages.
- **Custom Styling:** Uses CSS to create a cohesive visual design.

## Technologies Used

- **HTML5** — Website structure and content
- **CSS3** — Layout, typography, and styling
- **JavaScript** — Basic dynamic functionality

## Project Structure

The website consists of five main pages:

1. Home
2. About
3. Gallery
4. Team
5. Contact

Shared styling and navigation help maintain a consistent user experience across the website.
